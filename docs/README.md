# Patwadi documentation index

Canonical documentation lives in **`docs/` at the git repository root** (`E:\PatwadiApp\patwadi\docs\`).

## Workspace note

If you do not see this folder in the Cursor sidebar, you may have opened the **nested duplicate** at `patwadi-app/patwadi/` instead of the repo root. That path is gitignored and only holds stale copies.

**Recommended:** open the repo root (`E:\PatwadiApp\patwadi`) or use `patwadi.code-workspace` at the root. Do not rely on `patwadi-app/patwadi/docs/` — it is not the source of truth.
